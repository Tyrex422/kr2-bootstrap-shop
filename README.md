# Контрольная работа №2 — студия проката и обслуживания музыкальных инструментов «Резонанс»

Тема: «CSS-фреймворки: разработка интерфейса на Bootstrap».

## Страницы
- `index.html` — главная (hero, карусель акций, преимущества, категории, популярное, «Как арендовать», подписка);
- `catalog.html` — каталог: поиск по названию/бренду, фильтры (категория, цена), сортировка, пагинация, модальное окно быстрой брони;
- `product.html?id=N` — страница инструмента: вкладки (описание, характеристики, состояние), проверка доступности по датам, похожие инструменты;
- `rent.html` — аренда: фильтры по категории и сроку (цена за срок), условия, FAQ;
- `order.html` — форма бронирования;
- `contacts.html` — контакты, карта, форма с валидацией, отзывы, FAQ, соцсети.

## Bootstrap
Подключён через CDN (Bootstrap 5.3.8 + Bootstrap Icons 1.11.3), `css/custom.css` — после Bootstrap.
Компоненты: `navbar`, `card`, `btn`, `badge`, `alert`, `modal`, `form-control`, `form-select`, `input-group`, `form-check`, `accordion`, `carousel`, `tabs`, `pagination`, `breadcrumb`, `table`.

## Структура
```text
kr2-bootstrap-shop/
├── index.html, catalog.html, product.html, rent.html, order.html, contacts.html
├── css/custom.css      # 3 небольших правила
├── js/app.js           # данные инструментов, фильтры, пагинация, валидация
├── images/
└── README.md
```

## Как проверить
Открыть `index.html`, пройти по страницам, проверить поиск/фильтры/пагинацию, модальное окно, формы и адаптивность в DevTools (375/768/1024/1440 px).

## Самостоятельные доработки
Расширенный набор страниц, фильтры/сортировка/пагинация, расчёт стоимости за срок, проверка занятости дат, Bootstrap-валидация форм.
